# 🎙️ Script Voice Over: Showcase Data Engineer

**Target Durasi:** ~30-35 detik
**Tone/Gaya Bahasa:** Santai, *engaging*, percaya diri, tapi tetap menonjolkan keahlian teknis (profesional).

---

## [Scene 1: The Problem]
**Durasi:** ±7 detik
**Panduan Visual:** Teks "Monthly Report" dengan tanda tanya merah berkedip. Di sekelilingnya, ikon PostgreSQL, MongoDB, Excel, dan Google Analytics melayang berantakan dengan efek *glassmorphism* ala Apple.

**🗣️ Voice Over:**
> *"Pernah pusing disuruh bikin report bulanan, tapi datanya nyebar di mana-mana? Ada di database aplikasi, file Excel manual, sampai data web analytics... Ribet kan kalau harus narik manual satu-satu?"*

---

## [Scene 2: The Solution]
**Durasi:** ±5 detik
**Panduan Visual:** Layar tersapu bersih (ikon-ikon hilang). Teks "Solusinya: ETL & ELT" muncul perlahan, diikuti dengan kemunculan logo kincir angin **Apache Airflow** yang berputar elegan di tengah layar.

**🗣️ Voice Over:**
> *"Nah, di sinilah konsep ETL jadi penyelamat. Dan buat nge-orkestrasi semuanya biar jalan otomatis? Kenalin: Apache Airflow."*

---

## [Scene 3: The Workflow]
**Durasi:** ±15 detik
**Panduan Visual:** Menampilkan animasi *pipeline* yang mengalir lurus/terhubung:
1. **Trigger** (Ikon jam/play)
2. **Extract** (Garis bergerak narik data)
3. **Transform** (Ikon roda gigi memproses/merapikan data)
4. **Load** (Data masuk ke kotak Data Warehouse / BigQuery)

**🗣️ Voice Over:**
> *"Cukup set trigger-nya, Airflow bakal otomatis nge-extract data dari berbagai sumber tadi, men-transform data yang berantakan jadi rapi, lalu me-load semuanya ke Data Warehouse kamu. Tiap hari, tiap jam, bebas dan anti gagal!"*

---

## [Scene 4: Outro]
**Durasi:** ±8 detik
**Panduan Visual:** Transisi gelap/gelap elegan. Logo SVG personal kamu (dari file LogoMotion.tsx) perlahan membesar dengan pendaran/cahaya halus (*glow*), disertai nama/gelar "Data Engineer" di bawahnya.

**🗣️ Voice Over:**
> *"Nggak ada lagi drama narik data manual. Data rapi, bisnis happy. Tertarik ngobrol soal otomatisasi pipeline data? Let's connect!"*
